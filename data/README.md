# data

Q&A per Stack Exchange community, one directory per site (named by its API id, e.g. `stackoverflow`, `cooking`). Each holds:

- `README.md` — profile: reputation, badges, member since
- `answers.md` — answers, highest score first
- `questions.md` — questions, highest score first

Generated by [`track.py`](../track.py) from the [Stack Exchange API](https://api.stackexchange.com/docs); don't edit by hand.
